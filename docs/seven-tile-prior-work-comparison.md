# 7枚以下の待ち形: 既存研究との対照

比較対象は、firedial氏のZenn本
「[麻雀の多面待ちのパターンを全て求めてみた](https://zenn.dev/firedial/books/mahjang-waiting)」
の第9章「[待ち牌パターンリスト(7枚以下)](https://zenn.dev/firedial/books/mahjang-waiting/viewer/result_tile_7)」である。
本書は麻雀の待ちパターンをプログラムで列挙する個人の調査・実装記録であり、査読論文ではない。
公開ページの更新日は2025-03-14。

## どこまで対応づけられるか

Zennの一覧全体を本レポートの49既約分類へ直接対応づけることはできない。主な理由は、Zennの一覧が
7枚未満や非正規形も含み、1スート上のパターンを掲載する一方、本レポートは34牌種からなる7枚の
合法な通常形聴牌牌姿を対象とし、待ち核を保った完成面子の除去可能性で可約・既約を分けているためである。

牌姿単位で照合する場合は、少なくとも次の条件を満たすZenn掲載形に絞る。

1. 手牌が7枚ちょうどである。
2. 1〜9を本リポジトリの同一スート（例: 萬子）へ写し、各牌種の枚数が4枚以下である。
3. Zenn側の待ちに、すでに4枚使っている牌種を含まない。
4. どちらも通常形の待ちとして、牌姿を加えたときにできる待ち牌種の集合を比較する。

これらをそろえた後でも、Zennのパターン番号と本レポートの既約グループ番号が一致するとは限らない。
`waitDecompositionCodes` は待ち分解の部品種別を分類する内部表現であり、Zennの図示パターンや待ち牌集合
そのものと同一の分類キーではない。

したがって現時点で確実に述べられるのは、両者が「短い牌姿から通常形の待ちを列挙する」という問題意識を
共有すること、そして本リポジトリの7枚結果が、牌種・枚数上限・待ちの意味・分類単位を明示した別の
全列挙であることまでである。T001〜T026それぞれとの厳密な対応表を作るには、図から各行の牌姿と待ち牌を
読み取り、上記条件を適用したうえで本リポジトリの待ち結果と個別に照合する必要がある。
